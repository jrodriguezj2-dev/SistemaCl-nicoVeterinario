# Sistema de Control Clínico Veterinario

## Descripción

El Sistema de Control Clínico Veterinario es un proyecto desarrollado para
facilitar la administración de la información de una clínica veterinaria.

El sistema permite registrar propietarios, mascotas y veterinarios,
así como programar y consultar citas veterinarias.

## Objetivo

Desarrollar un sistema básico que permita gestionar información relacionada
con una clínica veterinaria de manera organizada.

## Funcionalidades

El sistema cuenta con las siguientes funcionalidades:

- Registrar propietario.
- Registrar mascota.
- Registrar veterinario.
- Programar cita.
- Consultar mascotas.
- Consultar citas.
- Registrar consultas veterinarias.
- Registrar diagnósticos.
- Registrar tratamientos.
- Actualizar expediente médico.
- Consultar expediente médico.
- Registrar vacunaciones.
- Registrar pagos.
- Cancelar citas.
- Generar reportes.

## Tecnologías utilizadas

- C#
- .NET
- Java
- BlueJ
- Draw.io
- GitHub
